# Preliminary Results and Expected Output

This folder contains preliminary results generated by the lightweight IoT authentication proof-of-concept.

## Authentication Demonstration

The preliminary authentication prototype verifies an IoT device using:

- Device ID
- Random nonce
- Timestamp
- HMAC-SHA256
- Replay detection
- RSSI-based context verification

A legitimate authentication request is expected to be accepted when all verification checks are successful.

## Security Test Results

The preliminary security testing includes:

- Legititimate authentication
- Replay attack
- Impersonation attack
- Message tampering
- RSSI outside the expected range

The expected behaviour is for legitimate authentication to be accepted while malicious or invalid authentication attempts are rejected.

## Performance Benchmark

The preliminary Python benchmark evaluates authentication using different numbers of registered devices, including:

- 1 device
- 10 devices
- 50 devices
- 100 devices

The preliminary measurements include authentication latency and communication payload size.

These results were generated using the Python proof-of-concept on a computer and should not be interpreted as final ESP32 or Raspberry Pi Pico performance results.

## Future Evaluation

Future physical testing is expected to evaluate:

- Computational cost
- Memory usage
- Energy consumption
- Authentication latency
- Communication overhead
- Scalability
- Resistance to spoofing
- Resistance to impersonation
- Resistance to replay attacks
- Resistance to Man-in-the-Middle attacks

Final measurements will be collected during physical testing using resource-constrained IoT devices such as ESP32 and Raspberry Pi Pico.
